# 三角洲 1080P 模式功能规范

## 目标

在显示器 OSD 控制台顶部提供“**三角洲 1080P 模式**”按钮。用户按下后，程序只针对 40C1R 显示器依次完成以下操作：

1. 将分辨率切换为 1920×1080。
2. 将系统缩放切换为 100%。
3. 将刷新率保持为 144Hz。
4. 打开 WeGame，由用户在 WeGame 内启动三角洲行动。

第 4 步采用用户认可的兜底行为。程序不得直接运行三角洲行动的游戏程序、官方启动器或 WeGameLauncher 目录中的启动器，以免绕过 WeGame 登录态。

## 入口与反馈

- 按钮位于窗口顶部工具条，文字为“三角洲 1080P 模式”。
- 显示器枚举完成前，按钮不可用。
- 枚举结果中没有 40C1R 时，按钮不可用，状态栏说明原因。
- 执行时按钮暂时不可用，状态栏显示当前阶段。
- 全部显示参数设置并复核成功后，程序才打开 WeGame。
- 完成后状态栏提示“已切换至 1920×1080、100%、144Hz，并已打开 WeGame；请在 WeGame 中启动三角洲”。

## 失败处理

- 40C1R 不支持目标显示模式时，不打开 WeGame，并明确提示目标模式不可用。
- 分辨率、缩放或刷新率任一设置失败或复核不符时，不打开 WeGame，并在状态栏显示失败项。
- 未找到 WeGame 时，保留已经成功切换的显示参数，并提示用户安装或修复 WeGame。
- 不改动其他显示器的分辨率、缩放或刷新率。

## 验收标准

- 在 40C1R 上执行后，系统读回值为 1920×1080、100%、144Hz。
- WeGame 启动路径来自本机安装信息，不含本机盘符或用户目录的硬编码。
- 代码中不存在直接启动三角洲行动游戏程序的逻辑。
- 编译产物更新到桌面“显示器 OSD 控制台”快捷方式当前指向的安装目录。
