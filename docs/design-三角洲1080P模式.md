# 三角洲 1080P 模式技术设计

功能表现以 [SPEC-三角洲1080P模式.md](SPEC-三角洲1080P模式.md) 为唯一依据，本文只规定实现方式。

## 代码结构

- 在 `NativeMethods` 中补充显示模式切换、显示适配器定位和逐显示器缩放所需的 Windows 接口声明。
- 新增 `DeltaDisplayMode`，集中负责 40C1R 识别、目标模式可用性检查、显示模式写入、缩放写入和结果复核。
- 新增 `WeGameLocator`，从 32 位和 64 位卸载信息中查找 WeGame 主程序，拒绝游戏目录或启动器目录作为候选。
- `MainForm` 只负责按钮状态、后台执行、状态栏反馈和在全部显示设置成功后启动 WeGame。

## 显示模式切换

- 使用 40C1R 对应的 `DeviceName` 定位目标屏幕。
- 先枚举目标屏幕支持的模式，只接受宽 1920、高 1080、刷新率 144 的模式。
- 复用该模式的色深等驱动参数，以测试标志检查后，再写入当前用户显示配置。
- 写入后重新读取目标屏幕当前模式，必须与目标完全一致。

## 缩放切换

- 通过目标屏幕的设备名取得显卡适配器标识和显示源编号。
- 读取该显示源的缩放范围，把最小缩放档设置为 100%。
- 写入后再次读取缩放档，必须确认当前值等于最小值。
- 该接口按显示源工作，因此不会修改其他显示器。

## WeGame 定位与启动

- 在当前用户和本机卸载信息中查找显示名称等于 `WeGame` 的条目。
- 只接受文件名为 `wegame.exe` 且文件真实存在的路径。
- 显示设置全部复核成功后，使用该路径启动或唤起 WeGame，不附加游戏程序参数。

## 验证

- 编译前检查文档与实现一致。
- 编译后运行静态检查，确认没有直接启动三角洲行动相关程序。
- 在本机 40C1R 上执行按钮路径，读取系统当前模式和缩放结果。
- 将编译产物复制到现有桌面快捷方式指向的位置，再从安装位置启动检查。
