# 一键开关 1080P 技术设计

功能表现以 [SPEC-三角洲1080P模式.md](SPEC-三角洲1080P模式.md) 为唯一依据，本文只规定实现方式。

## 代码结构

- 在 `NativeMethods` 中补充显示模式切换、显示适配器定位和逐显示器缩放所需的 Windows 接口声明。
- 新增 `MonitorIdentity`，把屏幕设备标识与系统上报的友好型号名对应起来，供 40C1R 识别使用。
- 新增 `DeltaDisplayMode`，集中负责目标模式可用性检查、显示模式写入、缩放写入和结果复核。
- 新增 `WeGameLocator`，从 32 位和 64 位卸载信息中查找 WeGame 主程序，拒绝游戏目录或启动器目录作为候选。
- `MainForm` 负责按钮状态、切换方向、后台执行、状态栏反馈和显示参数成功后的 WeGame 操作。
- 新增 5 秒倒计时确认窗，默认结果为不关闭 WeGame。

## 显示模式切换

- 使用 40C1R 对应的 `DeviceName` 定位目标屏幕。
- 读取当前分辨率决定切换方向，再枚举本次目标状态对应的 144Hz 模式。
- 复用该模式的色深等驱动参数，以测试标志检查后，再写入当前用户显示配置。
- 写入后重新读取目标屏幕当前模式，必须与目标完全一致。

## 缩放切换

- 通过目标屏幕的设备名取得显卡适配器标识和显示源编号。
- 游戏状态使用 100% 缩放档，桌面状态使用 125% 缩放档。
- 写入后再次读取缩放档，必须确认当前值等于本次目标值。
- 该接口按显示源工作，因此不会修改其他显示器。

## WeGame 操作

- 在当前用户和本机卸载信息中查找显示名称等于 `WeGame` 的条目。
- 只接受文件名为 `wegame.exe` 且文件真实存在的路径。
- 切到游戏状态并复核成功后，使用该路径启动或唤起 WeGame，不附加游戏程序参数。
- 切到桌面状态并复核成功后，在主界面线程显示 5 秒倒计时确认窗。
- 只有用户选择“是”时，才向 WeGame 安装目录内拥有主窗口的进程发送正常关闭请求；选择“否”或超时均不关闭。

## 验证

- 编译前检查文档与实现一致。
- 编译后运行静态检查，确认没有直接启动三角洲行动相关程序。
- 在本机 40C1R 上连续执行两个切换方向，分别读取系统当前模式和缩放结果。
- 将编译产物复制到现有桌面快捷方式指向的位置，再从安装位置启动检查。
