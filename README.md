# INNOCN 40C1R 显示器 OSD 控制台 (MonitorOSD)

用 Windows 软件代替显示器物理按键，直接控制 OSD 菜单参数。

> 适用/实测显示器：**INNOCN（联合创新 / 泰坦军团同源）40C1R**，40 英寸 3440×1440 @144Hz 带鱼屏，MStar 方案，MCCS 2.1。
> 程序按显示器上报的能力串动态生成界面，其他支持 DDC/CI 的显示器也可直接使用。

原理：通过 VESA **DDC/CI**（MCCS）标准协议，借助 Windows 自带的 `dxva2.dll` 直接读写显示器的 VCP 寄存器——效果等同于按显示器上的物理按键。

- 单文件、零依赖：只用 .NET Framework + Win32 API，无需安装任何 SDK
- 支持多显示器（顶部下拉框切换）
- 能力串之外的**隐藏参数**也能用：程序内置"扫描隐藏参数"功能，全量探测 0x00-0xFF 全部 256 个 VCP 码（本机实测扫出 60 个响应码，比能力串申报的多一倍）
- 读取带自动重试，避免显示器 DDC 总线限流导致的"读取失败"

## 运行

直接双击 `MonitorOSD.exe`（在右侧 Releases 或本地编译）。

自行编译（改代码后）：

```bat
build.bat
```

使用 Windows 自带的 .NET Framework 编译器（csc.exe），无需安装任何东西。

## 40C1R 上实测可用的控制项（29 项）

| 分区 | 控制项 | 一键恢复 |
| --- | --- | --- |
| 常用 | 亮度、对比度、扬声器音量（滑条）；静音；输入源 HDMI-1 / HDMI-2 / DP-1 / DP-2（切换前有黑屏提醒）；画面模式（标准/影院/游戏/竞速）；色彩模式（暖色 6500K / 冷色 9300K / 用户 1-2）；屏幕方向（0°/90°）；电源模式（开机/关闭/待机，"关闭"动鼠标即唤醒） | 恢复亮度/对比度 |
| 图像与颜色 | 锐度、红/绿/蓝增益、红/绿/蓝黑电平、色温（连续 0-100）（滑条）、动态背光 | 恢复颜色默认 |
| 恢复默认 | 恢复亮度/对比度、恢复颜色、恢复出厂设置（带二次确认） | — |
| 只读信息 | 刷新率（实测上报 144.7Hz）、行频率、固件版本、VCP 版本、累计使用时长、**系统分辨率**（显卡侧，附"打开 Windows 显示设置"按钮） | — |
| 厂商隐藏参数 | 点底栏"扫描隐藏参数"后出现：能力串之外有响应的厂商私有码（只读展示，如 0xE1/0xE3/0xFD 等） | — |

其中**扬声器音量、静音、RGB 黑电平、连续色温**不在显示器能力串里，是全量扫描发现的隐藏可用通道。

## 一键恢复

- 每个可编辑分组的标题行右侧有**分组恢复按钮**（常用→恢复亮度对比度；图像与颜色→恢复颜色默认）
- 顶部有**一键恢复全部**：依次执行 0x05（亮度/对比度出厂）+ 0x08（颜色默认），带确认弹窗；输入源、电源、画面模式等不受影响
- 恢复出厂设置（0x04，会清除所有用户设置，含厂商模式数据）单独放在"恢复默认"区，独立确认

## 为什么没有分辨率 / 比例 / 尺寸调节？

- **分辨率、刷新率由显卡（Windows/GPU）控制**，显示器 OSD 里本来就没有这个概念。程序在"只读信息"区显示系统当前分辨率，并提供"打开 Windows 显示设置"直达按钮
- **画面比例/缩放**属于厂商功能：对 40C1R 全量扫描 0x00-0xFF 后确认**没有任何比例/缩放类 VCP 码响应**，即该功能没有接 DDC 通道，软件无法触达，只能在显示器按键的 OSD 里调
- **尺寸/位置**（水平/垂直位置等）是 VGA 模拟时代的参数（0x20/0x30）：数字接口（HDMI/DP/USB-C）下虽能读到值但调节无效，故不提供

## 排错

- **所有参数读不出来**：先运行诊断脚本（只读，不改任何设置）：

  ```powershell
  powershell -ExecutionPolicy Bypass -File tools\check-ddc.ps1
  ```

  - 进显示器 OSD 菜单确认 **DDC/CI** 开关已打开（部分品牌默认关闭）
  - 经 USB-C 扩展坞/转接器连接时，部分扩展坞会丢弃 DDC 通道，尽量直连
  - 笔记本内置屏幕不走 DDC/CI，不受支持
- **某些项"读取失败"或数值怪**：厂商固件实现不标准，属正常现象，跳过即可
- **设置后无变化**：部分参数只在特定输入源/模式下生效，或显示器拒绝该值

其他工具：

```powershell
# 全量扫描 0x00-0xFF 所有响应码（只读，约 20 秒）
powershell -ExecutionPolicy Bypass -File tools\vcp-scan.ps1

# 查询本机显示器品牌型号（EDID/WMI）
powershell -ExecutionPolicy Bypass -File tools\get-monitor.ps1
```

## 界面说明

| 位置 | 内容 |
| --- | --- |
| 顶部 | 显示器切换、重新枚举、重读数值、**一键恢复全部** |
| 分组标题行 | 可编辑分组右侧带**分组恢复按钮** |

滑条有约 0.26 秒防抖，松手才写入，避免拖动时指令刷屏。

## 已知边界

- 只能控制显示器**声明支持或实测响应**的标准 MCCS 参数；厂商私有功能（游戏准星、背光分区、HDR 切换、画面比例等）不在 DDC 标准内
- HDR、OSD 锁定等厂商功能各品牌实现差异大，不保证可用
- 与 Twinkle Tray、NirSoft ControlMyMonitor 原理相同，本项目胜在按能力串动态生成界面、隐藏参数扫描、零依赖、源码可自行扩展
